# Package Manager

vole 内置了一个最小 package manager，用于初始化项目和从 npm registry 安装依赖。

它不是 npm / pnpm / yarn 的完整替代品，而是为 runtime 提供基础的包获取能力。

## CLI

```sh
vole init my-app
vole install
vole install lodash
vole install lodash@^4.17.0
```

## 核心能力

| 能力 | 说明 |
| --- | --- |
| `init_project(name, dir)` | 创建项目目录、`package.json` 和默认 `main.js`。 |
| `install_packages(packages, dir)` | 从 npm registry 安装指定包。 |
| `install_all(dir)` | 读取当前项目 `package.json` 的 dependencies 并安装。 |

## `package.json`

默认生成：

```json
{
  "name": "project",
  "version": "1.0.0",
  "main": "main.js",
  "type": "module",
  "dependencies": {}
}
```

## 安装流程

安装单个包时，package manager 会：

1. 解析 package spec，例如 `name` 或 `name@versionRange`。
2. 请求 npm registry。
3. 解析实际版本。
4. 获取 tarball 地址。
5. 下载 tarball。
6. 解压到 `node_modules/<name>`。
7. 写回 `package.json.dependencies`。

## 设计边界

- 当前只处理 dependencies。
- 不实现 lockfile。
- 不实现 lifecycle scripts。
- 不实现 workspace。
- 不实现 peer dependency resolver。
- 不做 Node.js package manager 兼容承诺。
