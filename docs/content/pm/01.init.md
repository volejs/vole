# Project Init

`vole init` 用于快速创建一个可以被 vole 执行的项目目录。

## 命令

```sh
vole init
vole init my-app
vole init my-app ./examples/my-app
```

参数：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `name` | `my-project` | 项目名，同时写入 `package.json.name`。 |
| `dir` | `.` | 初始化目录。 |

## 生成文件

`init_project()` 会创建目标目录，并写入：

```txt
package.json
main.js
```

如果 `main.js` 已经存在，不会覆盖它。

默认 `main.js`：

```js
console.log("Hello from vole runtime!");
```

## 注意事项

- `package.json` 会被重新写入。
- `main.js` 只在不存在时创建。
- 生成的项目默认使用 ESM：`"type": "module"`。

## 实现位置

- `PackageManager::init_project`
- `crates/package/src/lib.rs`
