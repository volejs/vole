# Package Install

`vole install` 从 npm registry 安装依赖到当前目录的 `node_modules`。

## 命令

```sh
vole install
vole install lodash
vole install lodash@latest
vole install lodash@^4.17.0
```

行为：

| 命令 | 说明 |
| --- | --- |
| `vole install` | 读取当前目录 `package.json.dependencies` 并全部安装。 |
| `vole install <pkg...>` | 安装指定包并写回 dependencies。 |

## 版本解析

支持两种 package spec：

```txt
name
name@versionRange
```

当没有指定版本时，默认使用 `latest`。

非 `latest` 版本会使用 `semver::VersionReq` 在 registry 的版本列表中选择匹配的最高版本。

## 解包

tarball 会被下载并解压到：

```txt
node_modules/<package-name>
```

tarball 中的 `package/` 前缀会被去掉。

## 已知限制

- scoped package 的 `@scope/name` 解析目前不完整，因为 package spec 使用简单的 `split_once("@")`。
- 没有 lockfile，重复安装可能解析到不同版本。
- 没有 bin link。
- 没有 dependency graph 展开安装。
- 没有 lifecycle scripts。

## 实现位置

- `PackageManager::install_packages`
- `PackageManager::install_all`
- `crates/package/src/lib.rs`
