# Runtime Extensions

`ExtensionRegistry` 是 runtime 初始化全局 Web API 的轻量注册器。它收集一组 `fn(&Ctx) -> Result<()>` 初始化函数，并在 VM 启动时一次性执行。

## 用途

全局能力包括：

- `console`
- timers
- `performance`
- `URL`
- `Blob` / `File`
- Streams
- Events
- `fetch`
- Web Crypto
- `WebAssembly`

这些能力不是通过 `import` 暴露，而是在 VM 初始化阶段挂载到 `globalThis`。

## 注册方式

扩展初始化函数通常形态如下：

```rust
pub fn init(ctx: &Ctx) -> Result<()> {
    let globals = ctx.globals();
    globals.set("SomeGlobal", value)?;
    Ok(())
}
```

然后由 runtime 的 bindings 初始化流程统一注册。

## 设计取舍

这种方式很直接：

- 每个 Web API 独立 crate 维护自己的初始化逻辑。
- runtime 可以控制初始化顺序。
- binding crate 不需要知道 CLI 或 VM 细节。

限制也很明确：

- 初始化顺序仍然重要，例如 `AbortSignal` 依赖事件系统。
- 扩展初始化失败会导致 VM 创建失败。
- 当前 registry 只处理同步初始化函数。

## 注意事项

- 新增全局 Web API 时，应优先放到 `crates/global_bindings/<name>`。
- 共享底层能力应放到 `crates/core`，不要复制到每个 binding crate。
- 如果能力是系统模块，优先放到 `vole:*`，不要污染 `globalThis`。

## 实现位置

- `crates/runtime/src/extensions.rs`
- `crates/runtime/src/bindings.rs`
- `crates/global_bindings/*`
