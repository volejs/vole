# FFI

`vole:ffi` 通过 libffi 和动态库加载提供本机函数调用。它适合明确掌握 ABI 的集成，不是任意 C/C++ 库的自动绑定器。

## 工作流程

1. 打开目标平台的动态库。
2. 按真实 ABI 声明函数参数和返回值。
3. 调用函数。
4. 在不再使用函数时关闭库句柄。

具体的 `open`、`define`、`call` 和 `close` 示例见 [vole:ffi](/modules/ffi/)。

## 平台与安全边界

动态库路径和符号随操作系统变化。必须保证调用约定、参数类型、指针有效期和库生命周期正确；错误声明可能导致进程崩溃，而不只是 JavaScript 异常。

不要将来自不可信输入的库路径或符号直接交给 FFI。日常文件和进程任务优先选择已有的 [系统模块](/modules/overview/)。
