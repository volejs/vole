# Calculate a SHA-256 digest

```js
const input = new TextEncoder().encode("hello vole");
const digest = await crypto.subtle.digest("SHA-256", input);
const hex = Array.from(new Uint8Array(digest))
  .map((byte) => byte.toString(16).padStart(2, "0"))
  .join("");
console.log(hex);
```

保存为 `digest.js`，运行 `vole run digest.js`。

摘要不是加密，也不适合作为密码存储方案。这个例子只展示数据编码与摘要 API；Web Crypto 支持范围见 [Globals & Web APIs](/modules/globals/)。
