# Test Runner

vole 内置一个轻量测试运行器，由 CLI 的 `vole test` 和模块 `vole:test` 组成。

它不是 Jest 兼容层，目标是提供 runtime 自身测试和简单项目测试所需的最小能力。

## 命令

```sh
vole test
vole test tests/
vole test tests/example_test.js
```

文件发现规则：

- 文件名以 `_test.js` 结尾。
- 文件名以 `_test.ts` 结尾。
- 递归扫描目录。
- 跳过 `target`、`node_modules`、`.git` 和隐藏目录。

## 执行流程

1. CLI 收集测试文件。
2. 创建一个新的 `Vm`。
3. 依次执行测试文件。
4. 执行：

```ts
import { run } from "vole:test";
await run();
```

5. 如果存在失败用例，进程以非零状态退出。

## 异步收尾

测试执行会等待：

- 测试函数返回的 Promise。
- timer idle。
- managed `vole:until` scope drain。

测试场景的 drain timeout 是 `60_000ms`。

## 实现位置

- `crates/cmd/src/main.rs`
- `crates/runtime/src/vm.rs`
- `crates/modules/src/js_shims/test.js`
