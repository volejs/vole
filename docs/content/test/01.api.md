# vole:test API

`vole:test` 提供测试注册、分组和 hook API。

## 导入

```ts
import {
  afterAll,
  afterEach,
  beforeAll,
  beforeEach,
  describe,
  it,
  test,
} from "vole:test";
```

## API

| API | 说明 |
| --- | --- |
| `test(name, fn)` | 注册一个测试用例。 |
| `test({ name, fn })` | 对象形式注册测试用例。 |
| `describe(name, fn)` | 创建测试套件。 |
| `it(name, fn)` | `test()` 的别名。 |
| `beforeAll(fn)` | 当前 suite 执行前运行。 |
| `afterAll(fn)` | 当前 suite 执行后运行。 |
| `beforeEach(fn)` | 当前 suite 每个测试前运行。 |
| `afterEach(fn)` | 当前 suite 每个测试后运行。 |
| `run()` | 运行当前 VM 中注册的测试。 |

## 示例

```ts
import { beforeEach, describe, test } from "vole:test";

describe("counter", () => {
  let value = 0;

  beforeEach(() => {
    value = 1;
  });

  test("increments", () => {
    value += 1;
    if (value !== 2) {
      throw new Error("expected value to be 2");
    }
  });
});
```

## 失败判断

测试失败由异常或 Promise rejection 表达：

```ts
test("fails", async () => {
  throw new Error("boom");
});
```

当前没有内置 assertion API，可以使用普通 JS 判断并抛错。

## 输出

成功：

```txt
  ✓ adds
```

失败：

```txt
  ✗ adds
    Error: ...
```

最后输出汇总：

```txt
1 passed, 0 failed
```
