# vole:exec

`vole:exec` 提供命令执行和子进程启动能力。该模块弱化 Node.js child_process 概念，更接近系统执行工具。

## 导入

```ts
import { exec, execSync, spawn } from "vole:exec";
```

## API

| API | 说明 |
| --- | --- |
| `exec(command, options?)` | 异步执行 shell command，返回 stdout/stderr/status。 |
| `execSync(command, options?)` | 同步执行 shell command。 |
| `spawn(command, args?, options?)` | 启动子进程，返回轻量进程句柄。 |

## 示例

```ts
import { exec, spawn } from "vole:exec";

const result = await exec("echo vole");
console.log(result.stdout);

const child = spawn("sleep", ["10"]);
child.kill("SIGTERM");
```

## 注意事项

- `exec`/`execSync` 是 shell 风格执行，命令拼接需要自行处理注入风险。
- `spawn` 返回的句柄目前只暴露 `pid` 和 `kill()`。
- 进程信号相关能力可参考 [vole:signal](signal.md)。
