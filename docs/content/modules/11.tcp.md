# vole:tcp

`vole:tcp` 提供 TCP client/server 低层字节流能力。

## 导入

```ts
import { connect, listen } from "vole:tcp";
```

## API

| API | 说明 |
| --- | --- |
| `connect(host, port)` | 连接 TCP server。 |
| `listen(port, host?)` | 监听 TCP 端口。 |
| `socket.read(size?)` | 读取字节。 |
| `socket.write(data)` | 写入字节。 |
| `socket.close()` | 关闭连接。 |
| `server.accept()` | 接受连接。 |

## 示例

```ts
import { listen } from "vole:tcp";

const server = await listen(9000, "127.0.0.1");
const socket = await server.accept();
await socket.write(new TextEncoder().encode("hello"));
```

## 注意事项

- 该模块不实现 HTTP、TLS 或 framing。
- HTTP server 请使用 [vole:http](http.md)。
- TLS 设计见 [vole:tls](tls.md)。
