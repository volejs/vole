# vole:os

`vole:os` 暴露当前进程的基础系统信息、工作目录、退出控制和标准输出/错误流。

## 导入

```ts
import { cwd, chdir, pid, stdout, exit } from "vole:os";
```

## API

| API | 说明 |
| --- | --- |
| `cwd()` / `chdir(path)` | 获取或修改当前工作目录。 |
| `uptime()` | 当前进程运行时间。 |
| `memoryUsage()` | 内存使用信息。 |
| `getExitCode()` / `setExitCode(code)` | 读取或设置默认退出码。 |
| `exit(code?)` / `abort()` | 退出或中止进程。 |
| `args`, `argv0`, `pid`, `ppid` | 进程参数和 pid 信息。 |
| `platform`, `arch`, `version`, `versions` | 平台与 runtime 版本信息。 |
| `stdout`, `stderr` | 文本输出对象。 |

## 示例

```ts
import { cwd, pid, stdout } from "vole:os";

stdout.write(`pid=${pid}\n`);
stdout.write(`cwd=${cwd()}\n`);
```

## 注意事项

- `exit()` 和 `abort()` 会终止当前进程。
- `stdout.writeAsync()` 当前保持兼容语义，不应假设完整 Web Stream 行为。
- 进程执行能力在 [vole:exec](exec.md)，信号能力在 [vole:signal](signal.md)。

## 底层实现

- JS shim：`crates/modules/src/js_shims/os.js`
- Native binding：`crates/raw_bindings/os`
