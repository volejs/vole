# vole:udp

`vole:udp` 提供 UDP datagram socket 能力。

## 导入

```ts
import { createSocket } from "vole:udp";
```

## API

| API | 说明 |
| --- | --- |
| `createSocket(port?, host?)` | 创建并绑定 UDP socket。 |
| `socket.send(data, remoteHost, remotePort)` | 发送一个 datagram。 |
| `socket.recv(size?)` | 接收一个 datagram。 |
| `socket.localAddress()` | 返回本地地址。 |
| `socket.close()` | 关闭 socket。 |

## 示例

```ts
import { createSocket } from "vole:udp";

const socket = await createSocket(0, "127.0.0.1");
console.log(await socket.localAddress());
await socket.close();
```

## 注意事项

- UDP 不保证可靠性、顺序或重传。
- `recv()` 每次解析一个 datagram。
- DNS over UDP 等高级协议应在上层模块实现。

## 底层实现

- JS shim：`crates/modules/src/js_shims/udp.js`
- Native binding：`crates/raw_bindings/udp`
