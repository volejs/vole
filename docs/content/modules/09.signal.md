# vole:signal

`vole:signal` 提供进程信号发送、信号能力查询，以及 native `SignalStream` 订阅。

## 导入

```ts
import { sendSignal, stream, SignalStream } from "vole:signal";
```

## API

| API | 说明 |
| --- | --- |
| `sendSignal(pid, signal?)` | 向进程发送信号。 |
| `killProcess(pid, signal?)` | `sendSignal` alias。 |
| `listSignals()` | 列出 runtime 支持的信号名。 |
| `isSupported(signalName)` | 判断信号名是否被识别。 |
| `new SignalStream(signals?)` | 创建 native 信号订阅流。 |
| `stream(signals?)` | 创建 `SignalStream` 的便利函数。 |

## 示例

```ts
import { stream } from "vole:signal";

for await (const signal of stream(["SIGINT", "SIGTERM"])) {
  console.log("received", signal);
}
```

## 注意事项

- `SignalStream` 是 native class，不是 JS subclass。
- `SignalStream` 同时支持 `EventTarget` 和 async iterator。
- 不同平台支持的信号集合可能不同。

## 底层实现

- JS shim：`crates/modules/src/js_shims/signal.js`
- Native binding：`crates/raw_bindings/signal`
