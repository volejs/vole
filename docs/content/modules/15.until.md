# vole:until

`vole:until` 提供 runtime 生命周期延长原语，用于跟踪后台异步工作。

## 导入

```ts
import { WaitUntil, drainManaged } from "vole:until";
```

## API

| API | 说明 |
| --- | --- |
| `new WaitUntil(options?)` | 创建生命周期 scope。 |
| `scope.waitUntil(promise)` | 追踪一个 promise-like 后台任务。 |
| `scope.drain(timeout?)` | 等待 scope 变为空闲。 |
| `scope.close()` | 关闭 scope，拒绝新任务。 |
| `drainManaged(timeout?)` | 等待所有 managed scope。 |
| `managedPendingCount()` | 返回 managed pending 数量。 |
| `managedScopeCount()` | 返回 managed scope 数量。 |

## 示例

```ts
import { WaitUntil } from "vole:until";

const until = new WaitUntil();
until.waitUntil(Promise.resolve().then(() => console.log("background")));
await until.drain(30_000);
```

## 注意事项

- `WaitUntil` 不是 cancellation token。
- promise rejection 会通过 `reportError` 报告。
- `managed: false` 可创建不加入 runtime registry 的本地 scope。
