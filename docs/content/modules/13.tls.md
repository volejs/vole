# vole:tls

`vole:tls` 是 TLS 能力探测模块。当前还是占位实现。

## 导入

```ts
import { getInfo, isAvailable, isSupported } from "vole:tls";
```

## API

| API | 说明 |
| --- | --- |
| `isSupported()` | 当前 TLS 模块是否可用。 |
| `isAvailable()` | `isSupported()` alias。 |
| `getInfo()` | 返回 `{ enabled }`。 |

## 示例

```ts
import { getInfo } from "vole:tls";

console.log(getInfo());
```

## 注意事项

- 当前返回 `enabled: false`。
- 后续可承载 TLS client/server、证书和 ALPN 能力。
- HTTP/3/TLS 相关设计不应直接塞进 TCP API。
