# vole:wasm

`vole:wasm` 暴露当前 WebAssembly shim 的 importable 入口。runtime 也会设置全局 `WebAssembly`。

## 导入

```ts
import { compile, instantiate, Module, Instance } from "vole:wasm";
```

## API

| API | 说明 |
| --- | --- |
| `compile(bytes)` | 编译 wasm bytes 为 `Module`。 |
| `instantiate(bytes, imports?)` | 编译并实例化 wasm。 |
| `Module` | 模块包装类。 |
| `Instance` | 实例包装类。 |
| `Memory` | 当前 shim 的内存读写 helper。 |
| `CompileError`, `RuntimeError` | wasm 错误类。 |

## 示例

```ts
import { compile } from "vole:wasm";

const bytes = await fetch("/module.wasm").then((res) => res.arrayBuffer());
const module = await compile(bytes);
console.log(module);
```

## 注意事项

- 当前由 `wasmi` 支撑，仍是部分 WebAssembly 实现。
- streaming compile/instantiate 等浏览器 API 尚未完整覆盖。
- 全局 `WebAssembly` 会被该 shim 设置。

## 底层实现

- JS shim：`crates/modules/src/js_shims/wasm.js`
- Native binding：`crates/raw_bindings/wasm`
