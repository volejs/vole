# Global Web APIs

`crates/global_bindings/*` 提供 vole 的全局 Web API。它们不是 `vole:*` 模块，而是在 runtime 初始化时直接安装到 `globalThis`。

## 设计原则

- 优先对齐 Web API 和 WinterTC Minimum Common Web Platform API。
- 能 native first 的能力优先用 Rust native binding 实现。
- JS shim 只用于组合 API 或弥补 QuickJS 暴露形态，不承担核心状态。
- 不追求 Node.js 全局对象兼容。
- 浏览器专属 DOM/HTML/CSS 能力只在 runtime 场景有意义时实现。

## 已实现能力

| crate | 全局能力 | 说明 |
| --- | --- | --- |
| `base64` | `atob`, `btoa` | Base64 编码/解码。 |
| `blob` | `Blob`, `File` | Web File API 数据对象，`Blob.stream()` 接入 Streams。 |
| `compression` | `CompressionStream`, `DecompressionStream` | gzip/deflate/deflate-raw/brotli 流式压缩与解压。 |
| `console` | `console` | 日志输出、计时、断言等基础控制台能力。 |
| `crypto` | `crypto`, `CryptoKey`, `SubtleCrypto` | Web Crypto 子集，包含 digest、随机数和部分对称/非对称算法。 |
| `dom_exception` | `DOMException` | Web API 错误对象。 |
| `encoding` | `TextEncoder`, `TextDecoder`, `TextEncoderStream`, `TextDecoderStream` | 文本编码和编码流。 |
| `events` | `Event`, `EventTarget`, `CustomEvent`, `MessageChannel`, `AbortController` | 事件系统、消息通道和 abort 语义。 |
| `fetch` | `fetch`, `Request`, `Response`, `Headers`, `FormData` | Web Fetch API，底层使用 native HTTP client。 |
| `performance` | `performance`, `Performance` | High Resolution Time、mark/measure 基础能力。 |
| `report_error` | `reportError` | 运行时错误报告入口。 |
| `streams` | `ReadableStream`, `WritableStream`, `TransformStream` | Web Streams 基础实现。 |
| `structured_clone` | `structuredClone` | 结构化克隆能力。 |
| `timers` | `setTimeout`, `setInterval`, `setImmediate` | 计时器全局函数。 |
| `url` | `URL`, `URLSearchParams`, `URLPattern` | URL 解析、查询参数和 URLPattern。 |

## 与 `vole:*` 模块的关系

全局 Web API 是跨平台通用层。`vole:*` 模块是系统能力层，例如 [vole:fs](fs.md)、[vole:http](http.md)、[vole:dns](dns.md)。

例如：

```ts
const response = await fetch("https://example.com");
const url = new URL(response.url);
```

这些能力不需要 `import`。

```ts
import { readTextFile } from "vole:fs";

const text = await readTextFile("README.md");
```

系统能力需要显式导入。

## 当前边界

- WebAssembly 仍是部分实现，完整浏览器 API 尚未全部覆盖。
- Streams 已可用，但复杂 backpressure/pipe 边界仍需要持续对齐 WPT。
- Fetch 已按 Web API 方向实现，但远期仍需要更多 WPT 覆盖。
- DOM 只保留运行时有意义的事件和异常对象，不实现浏览器文档树。
