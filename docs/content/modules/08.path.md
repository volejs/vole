# vole:path

`vole:path` 提供跨平台路径处理函数。

## 导入

```ts
import { join, resolve, dirname, basename } from "vole:path";
```

## API

| API | 说明 |
| --- | --- |
| `join(...parts)` | 拼接路径。 |
| `resolve(...parts)` | 解析绝对路径。 |
| `dirname(path)` | 返回父目录。 |
| `basename(path, ext?)` | 返回文件名。 |
| `extname(path)` | 返回扩展名。 |
| `isAbsolute(path)` | 判断绝对路径。 |
| `relative(from, to)` | 计算相对路径。 |
| `parse(path)` / `format(object)` | 路径结构化解析和格式化。 |
| `sep`, `delimiter` | 平台路径分隔符。 |

## 示例

```ts
import { join, parse } from "vole:path";

const file = join("docs", "globals.md");
console.log(parse(file));
```

## 注意事项

- 该模块是系统路径工具，不处理 URL。
- URL 解析请使用全局 `URL` / `URLSearchParams`。
