# vole:env

`vole:env` 读写当前 vole 进程的环境变量，并支持加载指定 `.env` 文件。

## 导入

```ts
import { get, set, has, remove, entries, load } from "vole:env";
```

## API

| API | 说明 |
| --- | --- |
| `get(name)` | 读取环境变量，缺失时返回 `undefined`。 |
| `set(name, value)` | 设置当前进程环境变量。 |
| `has(name)` | 判断变量是否存在。 |
| `remove(name)` | 删除当前进程环境变量。 |
| `entries()` | 返回当前环境变量快照。 |
| `load(path)` | 从指定文件加载 `.env` 内容。 |
| `env` | 对象形式的同名 API。 |

## 示例

```ts
import { env, load } from "vole:env";

load("./config/.env");
env.set("VOLE_MODE", "dev");
console.log(env.get("VOLE_MODE"));
```

## 注意事项

- `load(path)` 必须传入文件路径，不会自动退回默认 `.env`。
- 环境变量修改只影响当前进程以及之后创建的子进程。
- 变量名不能为空，不能包含 NUL 或 `=`。

## 底层实现

- JS shim：`crates/modules/src/js_shims/env.js`
- Native binding：`crates/raw_bindings/env`
