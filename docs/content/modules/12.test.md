# vole:test

`vole:test` 是 vole 内置测试注册和运行 API，供 `vole test` 使用。

## 导入

```ts
import { test, describe, beforeEach } from "vole:test";
```

## API

| API | 说明 |
| --- | --- |
| `test(name, fn)` | 注册测试用例。 |
| `test({ name, fn })` | 对象形式注册测试用例。 |
| `describe(name, fn)` | 注册测试套件。 |
| `it(name, fn)` | `test` alias。 |
| `beforeAll`, `afterAll` | 套件级前后置 hook。 |
| `beforeEach`, `afterEach` | 用例级前后置 hook。 |
| `run()` | 运行当前 VM 注册的测试。 |

## 示例

```ts
import { describe, test } from "vole:test";

describe("math", () => {
  test("adds", () => {
    if (1 + 1 !== 2) {
      throw new Error("bad math");
    }
  });
});
```

## 注意事项

- 不是 Jest 兼容层。
- 断言通过抛错/Promise reject 表达。
- CLI 会在加载测试文件后调用 `run()`。
