# vole:fs

`vole:fs` 提供同步/异步路径操作，以及统一 `FileHandle` 文件句柄。

## 导入

```ts
import { readTextFile, writeFile, open } from "vole:fs";
```

## API 分组

| 分组 | API |
| --- | --- |
| 同步读写 | `readFileSync`, `readTextFileSync`, `writeFileSync` |
| 异步读写 | `readFile`, `readTextFile`, `writeFile` |
| 路径操作 | `exists`, `mkdir`, `readdir`, `stat`, `remove`, `rename`, `copyFile`, `realPath` |
| 同步路径操作 | `existsSync`, `mkdirSync`, `readdirSync`, `statSync`, `removeSync`, `renameSync`, `copyFileSync`, `realPathSync` |
| 句柄 | `open`, `FileHandle`, `Stats` |

## 示例

```ts
import { mkdir, open, readTextFile, writeFile } from "vole:fs";

await mkdir("tmp", { recursive: true });
await writeFile("tmp/hello.txt", "hello vole");
console.log(await readTextFile("tmp/hello.txt"));

const file = await open("tmp/hello.txt");
console.log(await file.read(5));
await file.close();
```

## 注意事项

- 同步 API 会阻塞当前 VM。
- 文本 API 使用 UTF-8。
- `FileHandle` 当前主要面向文件读写，目录能力还在设计中。
