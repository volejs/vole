# vole:ffi

`vole:ffi` 通过 libffi/libloading 调用动态库符号。它是低层能力，适合封装成更窄的项目内模块后再使用。

## 导入

```ts
import { open, close, call, define } from "vole:ffi";
```

## API

| API | 说明 |
| --- | --- |
| `open(path)` | 打开动态库，返回 opaque handle。 |
| `close(handle)` | 关闭动态库 handle。 |
| `call(handle, symbol, args?, options?)` | 直接调用 native symbol。 |
| `define(handle, symbol, options?)` | 创建可复用的 JS 函数包装。 |

## 示例

```ts
import { close, define, open } from "vole:ffi";

const lib = open("/usr/lib/libSystem.B.dylib");
const strlen = define(lib, "strlen", {
  parameters: ["cstring"],
  result: "usize",
});

console.log(strlen("vole"));
close(lib);
```

## 注意事项

- 参数和返回类型必须与 native ABI 精确匹配。
- 错误签名可能导致崩溃或内存破坏。
- JS shim 会维护 handle 表，避免使用无效 handle。

## 底层实现

- JS shim：`crates/modules/src/js_shims/ffi.js`
- Native binding：`crates/raw_bindings/ffi`
