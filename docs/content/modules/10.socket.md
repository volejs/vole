# vole:socket

`vole:socket` 提供 Unix domain socket 连接和监听能力。

## 导入

```ts
import { connect, listen } from "vole:socket";
```

## API

| API | 说明 |
| --- | --- |
| `connect(path)` | 连接 Unix domain socket。 |
| `listen(path)` | 监听 Unix domain socket。 |
| `socket.read(size?)` | 读取字节。 |
| `socket.write(data)` | 写入字节。 |
| `socket.close()` | 关闭连接。 |
| `server.accept()` | 接受连接。 |

## 示例

```ts
import { listen } from "vole:socket";

const server = await listen("/tmp/vole.sock");
const socket = await server.accept();
await socket.write(new TextEncoder().encode("hello"));
```

## 注意事项

- 该模块主要面向 Unix 平台。
- Windows 行为可能不可用或由后端决定。
- API 是低层字节流，不做协议 framing。
