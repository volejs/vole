# vole:dns

`vole:dns` 提供 native-first DNS 解析能力。公共模块只导出 Rust native 后端，核心状态、缓存和 resolver 初始化都在 `vole:raw:dns` 内部完成。

## 导入

```ts
import { lookupHost, lookupIp, DnsResolver } from "vole:dns";
```

## API

| API | 说明 |
| --- | --- |
| `lookupHost(hostname)` | 使用共享 resolver 解析主机名，返回 IP 字符串数组。 |
| `lookupIp(hostname)` | 返回 `{ address, family }` 结构化 IP 记录。 |
| `new DnsResolver(options?)` | 创建 native resolver 实例。 |
| `resolver.clearCache(hostname?)` | 清理 resolver-local cache 和 Hickory resolver cache。 |
| `resolver.cacheEnabled()` | 返回 resolver-local cache 是否启用。 |

## 示例

```ts
import { DnsResolver, lookupHost } from "vole:dns";

console.log(await lookupHost("localhost"));

const resolver = new DnsResolver({ cache: true });
console.log(await resolver.lookupIp("example.com"));
resolver.clearCache("example.com");
```

## 注意事项

- 当前实现基于 `hickory-resolver`。
- 默认会优先读取系统 DNS 配置；如果系统配置不可用，会 fallback 到公共 resolver。
- 当前公共 API 只暴露 A/AAAA 级别的主机解析。
- TXT/MX/SRV/CNAME/reverse lookup 可以在后续扩展。

## 底层实现

- JS shim：`crates/modules/src/js_shims/dns.js`
- Native binding：`crates/raw_bindings/dns`
