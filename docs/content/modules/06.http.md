# vole:http

`vole:http` 提供 HTTP client/server 辅助能力。请求处理优先使用 Web API 形态：`Request -> Response | Promise<Response>`。

## 导入

```ts
import { fetch, request, serve, Server } from "vole:http";
```

## API

| API | 说明 |
| --- | --- |
| `request(url, options?)` | `globalThis.fetch` 的便利封装。 |
| `fetch(input, init?)` | 显式导出的 fetch alias。 |
| `new Server(handler, options?)` | 创建 HTTP server handle。 |
| `serve(handler, options?)` | 创建 server 的便利函数。 |

## 示例

```ts
import { serve } from "vole:http";

const server = serve((request) => {
  return new Response(`hello ${new URL(request.url).pathname}`);
}, { port: 8080 });

await server.listen();
```

## 注意事项

- server handler 接收 Web `Request`，返回 Web `Response`。
- JS shim 维护 handler registry，native HTTP backend 通过 dispatcher 调用。
- 未来 waitUntil/request lifecycle 会在这里继续扩展。

## 底层实现

- JS shim：`crates/modules/src/js_shims/http.js`
- Native binding：`crates/raw_bindings/http`
